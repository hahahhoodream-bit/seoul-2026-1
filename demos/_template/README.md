# 📊 우리반 마음 지도 : 또래관계 네트워크 시각화 도구
초등학교 담임교사를 위한 학생들의 교우관계에 대한 데이터를 입력하면 관계도를 도식화하여 전반적인 관계 및 소외, 친밀도 등을 분석해주는 웹 애플리케이션입니다.

> 2026-1학기 클라우드 프로그래밍 · M20261509/원지은

---

## 1. **무엇을 할 수 있나요**

1. **(기능 1) 데이터 업로드 및 현황 확인**: 다중 인코딩 자동 감지 기능으로 엑셀 출력 CSV 파일을 깨짐 없이 업로드하고, 학급 전체의 응답 완성도 메트릭을 실시간 표시
2. **(기능 2) 관계도 네트워크 시각화**: `NetworkX`와 `Plotly`를 통해 학생 간 친밀(진녹색)/서먹(인디언레드) 관계를 화살표 그래프로 시각화하며, 노드 크기는 받은 선택의 누적 횟수를 반영
3. **(기능 3) 관계 분석 지표 및 사유 그룹 요약**: 친밀도 상위 5명과 소외도 상위 5명 명단을 추출하고, 파편화된 주관식 지목 사유들을 5가지 카테고리로 의미론적으로 분류 및 집계

## 2. **입력 CSV 형식**

| 컬럼명 | 타입 | 예시 | 필수 |
|--------|------|------|------|
| `name` | String | 홍길동 | ✅ |
| `best_friend` | String | 이영희 | ✅ |
| `distant_friend` | String | 김철수 | ✅ |
| `reason_pos` | String | 성격이 활발하고 착해요 | ✅ |
| `reason_neg` | String | 평소에 장난이 너무 심해요 | ✅ |

> 총 22행(학급 학생 수 기준), 5개 컬럼 모두 필수이며 빈 칸이 있으면 업로드 시 안내 메시지가 표시됩니다.

샘플: [`sample_data.csv`](sample_data.csv)

## 3. **로컬 실행**

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 4. **Streamlit Cloud 배포**

1. GitHub public 저장소에 푸시
2. <https://share.streamlit.io> → New app → 저장소·`app.py` 선택
3. Deploy

🚨 실제 학생 이름이 든 CSV는 **절대 저장소에 올리지 마세요.** `.gitignore`가 차단합니다.

## 5. **최근 개선사항 (v1.1)**

### 시각화 개선
- **색상 코드 정확화**: 초록색 → `#2E8B57` (진녹색), 빨강 → `#CD5C5C` (인디언레드)로 변경하여 가독성 향상
- **엣지 렌더링 개선**: 선 굵기 2 → 1.5로 조정, 불투명도 60% 추가로 그래프 복잡도 시각적 완화

### 사유 분류 로직 강화
- **키워드 확대**: 긍정/부정 사유의 주요 키워드를 각각 5개 이상으로 세분화
- **5가지 카테고리 체계**:
  - **긍정(친밀)**: ① 밝고 활발한 성격 ② 친절하고 배려심 ③ 취미·대화 ④ 자주 어울림 ⑤ 오래된 인연
  - **부정(서먹)**: ① 대화·교류 부족 ② 과도한 장난/갈등 ③ 성격차이/배려부족 ④ 함께할 기회 부족 ⑤ 특별한 이유 없는 서먹함
- **미분류 처리**: 키워드에 매칭되지 않는 답변 → "그 외 개인적 친밀감/거리감"으로 통합 집계
