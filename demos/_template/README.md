# 📊 우리반 마음 지도 : 또래관계 네트워크 시각화 도구

초등학교 담임교사를 위한 학생들의 교우관계에 대한 학급 설문 CSV를 업로드하면 관계를 도식화하여 전반적인 학생 성향 및 관계, 소외, 친밀도 등을 분석해주는 웹 애플리케이션입니다.

> 2026-1학기 클라우드 프로그래밍 · [[M20261509/원지은]]

---

## 1. 무엇을 할 수 있나요

1. **(기능 1) 데이터 업로드 및 현황 확인**: 다중 인코딩(UTF-8, CP949 등) 자동 감지 헬퍼를 통해 교사가 엑셀에서 추출한 CSV 파일을 깨짐 없이 안전하게 업로드하고, 학급 전체의 응답 완성도 메트릭과 데이터 표를 즉시 확인합니다.
2. **(기능 2) 관계도 네트워크 시각화**: `NetworkX`와 `Plotly`를 활용하여 학생 간의 친밀 관계(초록 화살표)와 서먹한 관계(빨간 화살표)를 인터랙티브 그래프로 도식화합니다. 노드의 크기는 '받은 선택의 총량'에 따라 동적으로 조절되며, 마우스 호버 시 세부 지표(친한 친구 N명 / 서먹한 친구 N명)가 쪼개져 나타납니다.
3. **(기능 3) 관계 분석 지표 및 사유 그룹 요약**: 학생별 받은 표시 수와 소셜 중심성 지표를 정량적으로 제공하며, 학급 내 친밀도/소외도 상위 5명 학생을 추출합니다. 파편화된 단어 빈도 분석 대신, 주관식 지목 사유를 텍스트 마이닝하여 비슷한 의미군끼리 결합한 '문장 형태의 요약 분석 결과'를 제공합니다.

## 2. 입력 CSV 형식

앱이 정상 작동하려면 학급 학생 수 설정(**정확히 22명**)에 맞추어 아래의 필수 영문 컬럼명을 가진 CSV 파일이 필요합니다. 빈 칸이 있을 경우 교사가 인지하기 쉽게 엑셀 줄번호 기반의 친절한 한글 에러 가이드를 제공합니다.

| 컬럼명 | 타입 | 예시 | 필수 | 설명 |
|--------|------|------|------|------|
| `name` | String | 홍길동 | ✅ | 학생 본인의 이름 |
| `best_friend` | String | 이영희 | ✅ | 가장 친하다고 생각하는 친구 이름 |
| `distant_friend` | String | 김철수 | ✅ | 다소 서먹하거나 어색한 친구 이름 |
| `reason_pos` | String | 성격이 활발하고 착해요 | ✅ | 친한 친구로 선택한 주관식 사유 |
| `reason_neg` | String | 요즘 대화가 부족해요 | ✅ | 서먹한 친구로 선택한 주관식 사유 |

샘플 파일 양식: [`sample_data.csv`](sample_data.csv) *(테스트용 가상 데이터)*

## 4. Streamlit Cloud 배포

2. <https://share.streamlit.io> → New app → 저장소·`app.py` 선택
3. Deploy

🚨 실제 학생 이름이 든 CSV는 **절대 저장소에 올리지 마세요.** `.gitignore`가 차단합니다.
