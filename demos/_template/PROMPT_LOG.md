# PROMPT_LOG.md

GitHub Copilot Chat에 입력한 프롬프트를 시간 순서대로 기록합니다.

> **왜?** 좋은 프롬프트의 감각은 시행착오를 봐야 늡니다. 코드를 베끼는 게 아니라 프롬프트를 배우는 과정입니다.

---

## 1. 프로젝트 초기 골격
* **Prompt:** Streamlit으로 "우리반 마음 지도 : 또래관계 네트워크 시각화 도구"를 만들 거야. 사용자는 초등학교 담임교사이고 파이썬 지식이 없어. 기본 페이지 설정과 제목, 캡션만 먼저 만들어줘.
* **결과:** 페이지 설정 + 제목/캡션 3줄. 깔끔함. ✅
* **교훈:** 사용자가 누구인지(초등 담임교사)를 명시하면 단순하고 읽기 쉬운 구조를 제안받을 수 있다.

## 2. CSV 구조 정의 및 검증 함수
* **Prompt:** 22명 학생 데이터(name, best_friend, distant_friend, reason_pos, reason_neg)를 입력받는 validate_csv(df)를 만들어줘. 5개 컬럼, 22행 확인, 빈 값(NaN, 공백) 감지, 상세한 한글 에러 메시지 포함.
* **결과:** 명세에 맞는 견고한 입력 검증. 사용자 실수를 사전 차단. ✅
* **교훈:** "22행, 5개 컬럼, 모두 필수" 같은 구체적인 조건이 정확한 검증을 만든다.

## 3. 사이드바 CSV 업로더 + 메트릭 카드
* **Prompt:** 사이드바 st.file_uploader로 CSV 업로더 구현. 한글(UTF-8, CP949, EUC-KR) 자동 감지 헬퍼 함수 포함. 업로드 시 st.columns(3)으로 메트릭(총 응답자, 응답 완료, 완성도%)를 표시.
* **결과:** 깔끔한 UX 구현. ✅
* **교훈:** 엑셀 저장 인코딩(CP949) 맥락을 주면 다중 인코딩 시도 코드를 견고하게 짤 수 있다.

## 4. 네트워크 그래프 시각화
* **Prompt:** NetworkX로 DiGraph 생성. best_friend는 초록, distant_friend는 빨간 화살표. Plotly로 인터랙티브 그래프 구현. 한글 깨짐 방지 위해 Plotly 활용.
* **결과:** 관계도 시각화 및 직관적 구분 완료. ✅
* **교훈:** 웹 배포 환경의 폰트 깨짐 방지를 위해 matplotlib 대신 Plotly를 선택하는 것이 현명하다.

## 5. 노드 크기 최적화
* **Prompt:** 네트워크 시각화에서 선택을 많이 받은 아이는 노드를 크게, 적은 친구는 작게 나타내줘.
* **결과:** in-degree에 따른 동적 노드 크기 조절 구현. ✅
* **교훈:** "in-degree" 같은 전문 용어보다 "많은 선택을 받은" 같은 직관적 설명이 더 효과적이다.

## 6. 환경 요인 트러블슈팅
* **Prompt:** 파이썬 코드 내 SyntaxError 문제 해결(자동 수정 기능 오작동 해결).
* **결과:** OS 및 개발 환경 텍스트 자동 대치 설정 확인 후 해결. 🛠️
* **교훈:** 에러가 코드 논리 오류가 아닐 수 있음을 인지하자.

## 7. 사유 그룹화 요약
* **Prompt:** 단어 빈도 방식 대신, 비슷한 의미의 주관식 사유를 묶어서 문장 형태로 요약해 줘.
* **결과:** "성격이 좋고 활발함(3명)" 형태로 요약 기능 구현. 🎉
* **교훈:** 단어 나열보다 의미 군집화가 교사에게는 훨씬 실용적이다.

## 8. 노드 마우스 오버 정보 개선
* **Prompt:** 그래프 노드 마우스 오버 시 "총 N명 (친밀 N / 서먹 N)" 정보가 상세히 보이게 수정.
* **결과:** 관계 데이터 상세 조회 기능 완료. ✅
* **교훈:** 합산 숫자보다 상황을 해석할 수 있는 분류 정보가 더 중요하다.

## 9. 친절한 에러 메시지
* **Prompt:** 데이터 검증 실패 시 파이썬 에러 대신 "엑셀의 몇 행, 어느 컬럼 확인" 형태의 한글 안내문 적용.
* **결과:** 안내문 수준의 에러 메시지 구현. 🎉
* **교훈:** 에러는 오류 알림이 아니라 사용자의 '다음 행동'을 가이드해야 한다.

## 10. .gitignore 보안 설정
* **Prompt:** 실제 학생 이름 포함된 CSV 유출 방지 위해 *.csv 차단 및 가상환경(.venv 등) 설정.
* **결과:** 실제 학생 정보 업로드 사고 원천 차단. ✅
* **교훈:** 교육용 앱은 코드보다 데이터 보안이 우선이다.

## 11. README 문서화
* **Prompt:** 파이썬 모르는 동료 교사용 사용 가이드(프로그램 개요, CSV 양식, 실행법, 보안 주의사항) 작성.
* **결과:** 한글 사용 가이드 완성. 🎉
* **교훈:** 설명서가 없으면 도구는 나 혼자만 쓰게 된다.

## 12. 기능 구조 간소화 (4개 → 3개)
* **Prompt:** 관계 분석 지표와 사유 요약을 합치고, 그래프 마우스 오버로 확인 가능한 수치는 표에서 제거.
* **결과:** 기능 3개로 구조 간소화. ✅
* **교훈:** "이 정보가 정말 여기 있어야 하나?"를 매번 고민해야 한다.

## 13. 최종 UI 정비
* **Prompt:** 불필요한 중심성 지표 삭제. 상위 5명 명단과 사유 요약 표만 남겨서 직관성 극대화.
* **결과:** 교사 의사결정 중심의 최종 UI 확정. ✅
* **교훈:** 숫자는 해석을 어렵게 한다. 교사가 즉시 활용 가능한 정보만 남기자.

## 14. 시각화 및 분류 로직 개선 (v1.1)
* **Prompt:** (1) 색상을 정확한 hex code로 변경(초록 → #2E8B57 진녹색, 빨강 → #CD5C5C 인디언레드). (2) 엣지 선 굵기 2→1.5 + 60% 투명도 추가. (3) 사유 키워드를 5가지 카테고리로 정체계 구성. (4) 분류 안 된 답변은 "그 외 개인적 친밀감/거리감"으로 통합 처리.
* **결과:** 더 정확한 색상 구분 + 향상된 가독성 + 견고한 분류 로직. 🎉
* **교훈:** UI 색상과 데이터 분류는 "충분히 괜찮은" 상태에서 정확도를 높이는 것이 중요하다. 사용자 피드백 없이도 스스로 개선할 여지가 있다.

|---|---|
| **도메인 맥락** | "교사의 엑셀 저장 방식(CP949)" 등 구체적 환경 제시 |
| **실패 모드 정의** | "어디가 틀렸는지 줄번호로 알려줘" 등 오류 해결 중심 |
| **제약 조건** | "Plotly 사용", "기능 3개 유지" 등 범위 제한 |
| **사용자 중심** | "파이썬 모르는 동료 교사"라는 타겟 명시 |

**나쁜 프롬프트 1순위:** "한글이 깨져, 어떻게 해?" 또는 "코드 에러 나는데 고쳐줘" → 원인을 추측하지 않고 던지면 Copilot도 추측만 한다.
