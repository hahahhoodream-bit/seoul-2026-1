# PROMPT_LOG.md

GitHub Copilot Chat에 입력한 프롬프트를 시간 순서대로 기록합니다.

> **왜?** 좋은 프롬프트의 감각은 시행착오를 봐야 늡니다.
> 코드를 베끼는 게 아니라 프롬프트를 배우는 과정입니다.

---

## 1. 프로젝트 초기 골격

* **Prompt:** Streamlit으로 "우리반 마음 지도 : 또래관계 네트워크 시각화 도구"를 만들 거야. 사용자는 초등학교 담임교사이고 파이썬 지식이 없어. 기본 골격만 만들어줄 수 있어?
* **결과:** 페이지 설정 + 제목/캡션 3줄. 깔끔함. ✅

---

## 2. CSV 구조 정의 및 검증 함수

* **Prompt:** 이 도구는 22명 학생의 교우관계 데이터를 입력받아. CSV 컬럼은 5개: name (학생 이름), best_friend (가장 친한 친구 이름), distant_friend (서먹한 친구 이름), reason_pos (친함 이유), reason_neg (서먹함 이유). 검증 함수 validate_csv(df)를 만들어줘. 다음을 확인해: 필수 컬럼 5개 모두 있는지, 정확히 22행인지 (학생 수), 모든 필드에 빈 값(NaN, 공백)이 없는지. 에러가 있으면 에러 메시지를 반환하고, st.error()로 보여준 후 st.stop()해줘.
* **결과:** 명세에 맞는 견고한 입력 검증. 사용자 실수를 사전 차단. ✅
* **교훈:** 단순히 "CSV 업로드" 대신 "22행, 5개 컬럼, 모두 필수" 같은 도메인 맥락을 주면 검증이 정확해진다.

---

## 3. 사이드바 CSV 업로더 + 메트릭 카드

* **Prompt:** 사이드바에 st.file_uploader로 CSV 업로드 위젯을 만들어줘. 업로드되면 한글(UTF-8, CP949, EUC-KR) 인코딩을 자동으로 감지하는 헬퍼 함수 read_csv_any()를 먼저 만들어줘. 업로드 전에는 "👈 왼쪽 사이드바에서 CSV 파일을 업로드하세요" 안내 메시지만 보이게 해줘. 업로드되면 상단에 st.columns(3)으로 3개의 메트릭을 띄워줘: 📋 총 응답자 (행 수), 👥 응답 완료 (빈 값 없는 행 수), ⚡ 완성도 (%). 그 아래로 st.dataframe으로 표 전체를 보여줘.
* **결과:** 깔끔한 UX. 교사는 즉시 응답 상황을 파악 가능. ✅
* **교훈:** 엑셀 CSV는 기본 CP949 → 다중 인코딩 시도가 필수. "한글이 깨져"보다 "교사가 엑셀에서 저장했을 때 보통 CP949" 라고 맥락을 주면 코드가 견고해진다.

## 4. 네트워크 그래프 시각화

* **Prompt:** NetworkX로 학생 관계도를 DiGraph로 만들어줘. 다음 두 함수를 구현해: 1. build_network_graph(df): 모든 학생을 노드로 추가, best_friend 엣지는 초록색 (color="green"), distant_friend 엣지는 빨간색 (color="red"), 화살표 방향: 자신 → 대상 친구 / 2. visualize_network(G): Plotly로 인터랙티브 그래프 생성, Spring layout으로 노드 자동 배치, 범례: "🟢 초록 화살표 = 친한 친구", "🔴 빨간 화살표 = 서먹한 친구", 제목: "또래관계 네트워크 (화살표 방향: 자신 → 대상)". matplotlib 말고 Plotly를 써줘. 한글이 자동으로 잘 나와.
* **결과:** 관계도가 한눈에 들어옴. 친밀/소외 관계를 색으로 직관적 구분. ✅
* **교훈:** Streamlit Cloud는 matplotlib 한글 폰트 미설치 → Plotly가 SVG 렌더링이라 한글 문제 없음. 도구 선택 시 배포 환경을 고려해야 한다.

## 5. 사회네트워크 분석 지표

* **Prompt:** calculate_network_metrics(df, G) 함수를 만들어줘. 각 학생마다 다음 7개 지표를 계산하고 DataFrame으로 반환해: 👍 받은 친밀표시, 👎 받은 소외표시, 🔗 중심성(NetworkX degree_centrality), 💚 선택한 친한친구, 💔 선택한 소외친구, 📊 관계성향("받은 친밀표시 > 받은 소외표시"면 "외향적", 반대면 "내향적"). 결과는 "👍 받은 친밀표시" 내림차순으로 정렬해줘. 그리고 화면에는: 📖 st.expander로 지표 설명 축약 가능하게, 📊 전체 지표 표, 🏆 친밀도 상위 5명, ⚠️ 소외도 상위 5명
* **결과:** 각 학생의 사회네트워크 위치를 정량적으로 파악 가능. 교사가 소외 위험군을 식별. ✅
* **교훈:** 명세 범위를 넘어, 교사 입장에서 "어떤 학생을 주목해야 할까?"에 답할 수 있도록 설계했다. → 도구가 산다.

## 6. 노드 크기를 선택 받은 횟수로 표현

* **Prompt:** 지금 네트워크 그래프 시각화에서 모든 노드가 같은 크기여서 아쉬워. 그 많은 선택을 받은 아이들의 이름을 친한 친구든 서먹한 친구든 좀 크게 나타나고 적은 선택을 받은 친구는 크기가 작게 나타나도록 도식화 할 수 있어? 선은 그대로 나타내고.
* **결과:** 노드 크기가 "받은 선택의 총 개수"에 따라 동적으로 조절됨. ✅
* **교훈:** 구체적인 산업 용어 대신 직관적 설명 사용이 중요 ("in-degree"가 아니라 "많은 선택을 받은" 이라고 표현)하며, 시각적 변수(크기)를 추가하면 데이터가 더 잘 읽힌다.

## 7. 환경 요인으로 인한 SyntaxError 해결 (트러블슈팅)

* **Prompt:** if df[col].isna().any() 또는 (df[col] == "").any(): SyntaxError: invalid syntax 에러가 발생해. 코드를 복사해서 붙여넣어도 자꾸 파이썬 코드 안에 한글 '또는', '및'이 들어가거나 st.success가 st.성공으로 멋대로 바뀌어. 어떻게 막아야 해?
* **결과:** OS 및 개발 환경의 '텍스트 자동 대치/맞춤법 교정' 오작동임을 확인하고 우회 해결. 🛠️
* **교훈:** 모든 에러가 소스코드 논리 오류는 아니다. 운영체제(OS) 입력기 같은 외부 요인이 코드를 오염시킬 수 있음을 인지해야 한다.

## 8. 주관식 사유 추출 방식 고도화 (의미별 문장 그룹화)

* **Prompt:** 단어를 쪼개서 빈도를 뽑아내는 기존 방식은 결과가 파편화되어 나와서 이상해. 차라리 이전 화면의 레이아웃이나 지표 설명은 그대로 유지하되, 주관식 이유를 비슷한 것끼리 묶어서 분석해 줘. 예를 들어 "성격이 좋다"와 "성격이 활발하다"를 하나의 의미군으로 묶어서 문장 형태로 요약해 표현하는 식으로 변경해 줘.
* **결과:** 파편화된 단어 나열에서 벗어나, 학급 경영에 즉각 참고할 수 있는 '유사 의미군 기반의 문장형 그룹 요약' 기능으로 고도화 성공. 🎉
* **교훈:** 텍스트 마이닝 시 단순 빈도 분석보다 도메인에 특화된 의미론적 그룹화(Clustering)가 실무 관점에서 훨씬 더 가치 있는 정보를 제공한다.

## 9. 관계도 노드의 호버(Hover) 상세 정보 시각화 개선

* **Prompt:** 기능 ②의 Plotly 네트워크 그래프에서 노드에 마우스를 올렸을 때 나오는 정보가 너무 단순해. 단순히 전체 '선택 받음' 횟수만 보여주지 말고, 이 학생이 받은 친밀 표시와 소외 표시가 각각 몇 개인지 쪼개서 `선택 받음: 총 N명 (친밀 N / 서먹 N)` 형태로 호버 툴팁(hovertext)이 나타나도록 `visualize_network` 함수를 수정해 줘. 선(Edge)의 색상과 노드 크기 로직은 그대로 유지해 줘.
* **결과:** 그래프 시각화 화면에서 정성적 관계 분포를 마우스 오버만으로 더 깊이 있게 파악할 수 있도록 기능 ② 고도화 완료. ✅
* **교훈:** 데이터 시각화 시 요약된 총합 데이터(Aggregate)뿐만 아니라, 세부 속성(Breakdown)을 인터랙티브 요소에 녹여낼 때 사용자의 탐색 가치가 높아진다.

## 10. 비전문가 교사를 위한 데이터 검증(Validation) 에러 메시지 고도화

* **Prompt:** 데이터 검증 실패 시 나오는 에러 메시지가 파이썬 지식이 없는 일반 교사들이 보기엔 조금 딱딱하고 불친절해. `validate_csv` 함수에서 필수 컬럼이 누락되었거나 빈 값이 있을 때, 단순히 프로그램 에러처럼 띄우지 말고 교사가 엑셀 창에서 쉽게 수정할 수 있도록 "엑셀 파일의 [컬럼명] 열에 빈 칸이 있는지 확인해 주세요. 누락된 행 번호: N행"과 같이 안내 문구를 아주 친절하고 구체적인 한글 문장으로 다듬어 줘.
* **결과:** 전체 기능 3개 틀 안에서 사용자(초등 교사)의 실제 예외 처리 문구 최적화 완료. 🎉
* **교훈:** 에러 메시지는 단순히 버그를 알리는 창이 아니라, 유저가 다음 행동을 올바르게 수행할 수 있도록 안내하는 "나침반" 역할을 해야 한다.
